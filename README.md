## 📌 Sobre o Projeto

Este é o código-fonte do meu portfólio pessoal de 2026. A ideia foi criar um espaço direto, limpo e com personalidade — misturando um design minimalista e moderno com pitadas nostálgicas (como o meu projeto paralelo de portfólio em **Orkut** 🖥️).

O site consome diretamente a **API do GitHub** para carregar os meus repositórios públicos, lê os `README.md` e extrai automaticamente as imagens e prints das pastas do projeto para exibi-las em um modal interativo.

## ✨ Principais Funcionalidades

- **Design Exclusivo:** Interface customizada, tipografia mista (`Manrope`, `DM Mono` e `Playfair Display`) e efeito de *grain* analógico.
- **Integração com o GitHub:** Busca dinâmica dos repositórios e projetos direto do meu perfil.
- **Leitor de README e Mídia:** Extração automática de imagens, capturas de tela e assets dos repositórios para visualização em destaque.
- **Destaque Especial (Orkut):** Uma seção interativa que resgata a estética clássica da antiga rede social.
- **Responsividade Total:** Adaptado para celulares, tablets e desktops.
